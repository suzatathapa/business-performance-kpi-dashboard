# Cleaned Data

This folder contains analysis-ready datasets generated from the raw sales data.

The files in this folder are created through the Python data-cleaning and analysis workflow.

## Files

- `sales_cleaned.csv` — cleaned transaction-level dataset with calculated Revenue, Profit, and Profit_Margin fields.
- `monthly_summary.csv` — monthly revenue, profit, and order summary.

These files are generated outputs and should be refreshed when the raw dataset or cleaning process changes.
